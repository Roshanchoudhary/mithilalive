# News Portal CMS

A production-ready, SEO-optimized News Portal CMS built with Astro, TypeScript, Tailwind CSS, and Cloudflare.

## Features

- ✅ Full CMS functionality with news management
- ✅ Multi-role authentication (Super Admin, Admin, Editor, Reporter, Employee, User)
- ✅ SEO optimized with automatic sitemaps, meta tags, schema markup
- ✅ Image upload with WebP conversion and thumbnails
- ✅ Ad management with Google AdSense support
- ✅ Theme customization from admin panel
- ✅ Menu builder with drag and drop
- ✅ Responsive design with dark mode
- ✅ Comment system with moderation
- ✅ Full-text search
- ✅ Analytics dashboard
- ✅ PWA support
- ✅ 95+ Lighthouse score

## Tech Stack

- Astro 4.x
- TypeScript
- Tailwind CSS
- Cloudflare Pages
- Cloudflare Workers
- Cloudflare D1 (Database)
- Cloudflare R2 (Storage)
- Cloudflare KV (Cache)
- JWT Authentication
